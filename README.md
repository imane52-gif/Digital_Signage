# Yazaki
Digital Signage


## 📝 Description du projet
Ce projet est une application web d'affichage dynamique (Digital Signage) développée pour **Yazaki**. Elle permet de gérer et d'afficher du contenu interactif, des tableaux de bord RH et des informations d'entreprise.

---

## 🛠️ Technologies utilisées
* **PHP** (Back-end)
* **HTML5 / CSS3 / JavaScript** (Front-end)
* **MySQL** (Base de données)

---

## 📂 Structure du projet
* `admin/Dashboard.php` : Tableau de bord principal de l'admin.
* `admin/Mon_profil.php` : Page de gestion du profil admin.
* `create_account.php` : creer un acc pour les nouveaus responsable .
* `api.php` : Endpoints API pour la communication des données.
* `action.php` : Traitement des formulaires et des actions utilisateur.
* `1ksp_yazaki.png` :le logo Yazaki.
* `bg-usine.png` :picture of Yazaki campus.
* `login.php`:la connexion.
* `logout.php`:la deconnexion.
* `db.php`:la connexion entre php and base de donnees MYSQL.
* `rh/Dashboard.php` : Tableau de bord principal de rh.
* `rh/Mon_profil.php` : Page de gestion du profil rh.
* `upload.php` :montre tou les tables dans la b ase de donnees.
* `uploads`:un dossier archiver les videos .
